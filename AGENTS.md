# Reglas de trabajo acordadas con el usuario

- No iniciar ninguna modificación sin una indicación expresa del usuario.
- Informar de un problema, enviar una captura o hacer una consulta no autoriza
  cambios en el código, la configuración, los scripts ni la documentación.
- Si el usuario pide «anotar», registrar únicamente la nota solicitada, sin
  implementar cambios en la aplicación.
- Una autorización permite completar el trabajo solicitado dentro de su alcance;
  no autoriza modificaciones adicionales por iniciativa propia.

Regla solicitada expresamente por el usuario el 30 de octubre de 2026.
